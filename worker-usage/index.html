How it works

{% if u.ready %}Checked {{ u.checked }}{% endif %}

Cloudflare counts every request a Worker answers and every row its database reads or writes, and publishes those counts through its GraphQL Analytics API. Once an hour the Worker asks for the last 30 days of its account (the free plan’s limits are per account) and keeps the answer as one row in its database, so viewing this page never calls the API. A GitHub Action copies that row into this page when the site is rebuilt, and the script on the page swaps in the newer figures.

The limits shown are Cloudflare’s for the free plan: 100,000 Worker requests a day, 10 ms of CPU per run, 5 million database rows read and 100,000 written a day, and 5 GB of storage. The Worker reads its analytics with a token that can only read them. Its code is in the worker folder of this site’s repository.
