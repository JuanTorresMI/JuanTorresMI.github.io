{%- if es %}

Los precios son del USDA, del reporte diario nacional de cerdo LAB planta, ventas negociadas de la tarde (LM_PK602): el promedio ponderado de las ventas negociadas del día, LAB planta empacadora, en dólares por quintal (100 lb). Divida entre 100 para el precio por libra. Son precios de mayoreo, muy por debajo de lo que cuesta el mismo corte en una tienda.{% if c and c.usda != "" %} El USDA lista este producto como “{{ c.usda }}”.{% endif %}{% if r %} El último reporte es del {{ r.date_es }}; el siguiente se espera el {{ r.next_due_es }}.{% endif %}

El tablero del cerdo tiene cada corte de hoy, la canal, los primales y todo el historial en descargas CSV. Fuente: Servicio de Comercialización Agrícola del USDA.

{%- else %}

Prices are USDA’s, from the National Daily Pork FOB Plant, Negotiated Sales afternoon report (LM_PK602): the weighted average of the day’s negotiated sales, FOB the packing plant, in dollars per hundredweight (100 lb). Divide by 100 for the price per pound. These are wholesale prices, well below what the same cut costs at a store.{% if c and c.usda != "" %} USDA lists this item as “{{ c.usda }}”.{% endif %}{% if r %} The latest report is for {{ r.date }}; the next is due {{ r.next_due }}.{% endif %}

The pork board has every cut for today, the cutout, the primals and the whole history as CSV downloads. Source: USDA Agricultural Marketing Service.
