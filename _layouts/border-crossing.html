{% if es %}Sobre estos números{% else %}About these numbers{% endif %}

{% if b %}{% if es %}Copiado el {{ b.as_of_es }}{% else %}Copied {{ b.as_of_en }}{% endif %}{% endif %}
{%- if es %}

Los agentes de cada cruce fronterizo publican la espera de los carriles comerciales aproximadamente cada hora en el sistema Border Wait Times de CBP. Un pequeño servicio en Cloudflare lo consulta cada media hora y guarda cada lectura una sola vez; de ese registro salen los promedios de los últimos 30 días. Los promedios del año anterior son los que publica la propia CBP. FAST es el carril para transportistas inscritos en ese programa de CBP.

Las horas son la hora local del cruce. Un carril cerrado o una actualización pendiente no se cuentan como cero, sino como dato desconocido. La lista de cruces con México muestra todos ahora mismo; el tablero en inglés explica cómo funciona todo, y los promedios se pueden descargar en CSV.{% if page.translation %} This page in English.{% endif %}

Fuente: Oficina de Aduanas y Protección Fronteriza de EE. UU. (CBP). Los datos son públicos; cualquier error al presentarlos es mío.

{%- else %}

Officers at each port of entry post the commercial lanes’ wait about once an hour to CBP’s Border Wait Times system. A small Cloudflare Worker reads it every half hour and keeps each reading once; the last-30-days averages come from that record. The averages from the year before are CBP’s own. FAST lanes are for carriers enrolled in CBP’s FAST program.

Times are the crossing’s local time. A closed lane or a pending reading counts as unknown, never as zero. The board has every crossing right now and how it all works, and the averages are a CSV download.{% if page.translation and page.translations_live %} Esta página en español.{% endif %}

Source: U.S. Customs and Border Protection. The numbers are public; any mistakes in presenting them are mine.
