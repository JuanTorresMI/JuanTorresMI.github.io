{% if es %}Sobre estos números{% else %}About these numbers{% endif %}

{% if b %}{% if es %}Copiado el {{ b.as_of_es }}{% else %}Copied {{ b.as_of_en }}{% endif %}{% endif %}
{%- if es %}

Los oficiales de cada puerto de entrada publican la espera de los carriles comerciales más o menos cada hora en el sistema Border Wait Times de CBP. Un pequeño servicio en Cloudflare lo consulta cada media hora y guarda cada lectura una sola vez; de ahí salen los promedios por día y hora, que CBP no publica. FAST es el carril para transportistas inscritos en ese programa de CBP.

Las horas son la hora local del cruce. Un carril cerrado o una lectura pendiente no se cuentan como cero, sino como dato desconocido. El tablero (en inglés) muestra todos los cruces ahora mismo y cómo funciona todo, y los promedios se pueden descargar en CSV.{% if page.translation %} This page in English.{% endif %}

Fuente: U.S. Customs and Border Protection. Los datos son públicos; cualquier error al presentarlos es mío.

{%- else %}

Officers at each port of entry post the commercial lanes’ wait about once an hour to CBP’s Border Wait Times system. A small Cloudflare Worker reads it every half hour and keeps each reading once; the averages by day and hour, which CBP doesn’t publish, come from that record. FAST lanes are for carriers enrolled in CBP’s FAST program.

Times are the crossing’s local time. A closed lane or a pending reading counts as unknown, never as zero. The board has every crossing right now and how it all works, and the averages are a CSV download.{% if page.translation and page.translations_live %} Esta página en español.{% endif %}

Source: U.S. Customs and Border Protection. The numbers are public; any mistakes in presenting them are mine.
