What this is

A combat simulator for one League of Legends champion, Kalista, on patch {{ t.patch }}. It builds her stats and her enemies’ from Riot’s Data Dragon files and the League Wiki, then plays fights out attack by attack: kill times against target dummies, two-way duels against a marksman, a bruiser, a tank and a mage, short lane trades, and 2v2, 3v3 and 5v5 teamfights.

At each completed-item spike it tries every candidate item, keeps the best paths with a beam search, and compares rune pages. Each build goal (fastest kill, best duel, hardest to kill, a solo queue carry) gets its own best build. The results above are the output of one full run.

The build editor runs the same Python simulator in your browser with Pyodide. Pick items, level and runes and it plays the fights for that build. Scores are relative between builds, not real win rates: positioning, skillshots, teammates and summoner spells aren’t modeled.

Run it yourself

The source is on GitHub. It is plain Python 3 with no packages; pytest is the only thing the tests need. ./run_all.sh runs the whole pipeline and writes the results page, ./kalista build yuntal ie ldr zerks --level 13 checks one build, ./kalista optimize --goal carry searches for the best one, and pytest --runslow runs the tests shown above.
