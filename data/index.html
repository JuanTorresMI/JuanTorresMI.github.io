Using the files

Each table is USDA's as published, one row per report line, with dates as YYYY-MM-DD and no thousands separators. Recent reports are refetched for 45 days, so corrections land. Columns never change order; a column USDA adds later goes at the end. Read one in Python with pd.read_csv("{{ site.url }}/data/usda-hog-prices/hog-prices-by-region.csv").
