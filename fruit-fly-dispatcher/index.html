Fruit Fly Dispatcher

A fruit fly's navigation circuit, wired neuron by neuron from the FlyWire connectome, runs a week of fresh-food deliveries against Google's OR-Tools. Each brain is tested at four levels of knowledge, from a fly with no memory that finds stores only by smell up to the live shelf data and GPS a real dispatcher has. At each level every brain drives the same truck with the same senses, so only the way it decides differs.

Memory against smell, inside the fly

A is where the fly remembers a store. B is a whiff: odor switches on hΔC cells that read the wind, and they write an upwind goal into the same goal cells, through their FlyWire synapses. Drag either around the compass; pull it toward the center to weaken it. The page runs the real circuit and finds every heading the fly would settle on.

What the wiring had to get right

Every direction the fly's circuit uses was derived from FlyWire wiring alone, then checked against something independent. None of the published numbers were fed in.
