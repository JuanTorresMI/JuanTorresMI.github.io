How it works

{% if b %}Copied {{ b.as_of_en }}{% endif %}

At every land port, CBP officers post how long the commercial lanes are backed up, about once an hour, to the agency’s Border Wait Times site. It’s the best public number there is, but it’s only ever the number right now. Nobody shows what a crossing is usually like on a Tuesday at 2 PM, which is what you need to plan a load.

  1. A Cloudflare Worker reads CBP every half hour. The same small Worker behind this site’s reefer rate board asks CBP’s public feed (no key needed) for every port, and keeps the ones with commercial lanes.
  2. Each reading is kept once, for good. A reading is stored with the time the port posted it, so asking twice in the same hour never counts it twice; times are the port’s own clock. The Worker holds the last two weeks in a small database on Cloudflare (D1), and every time the site is rebuilt they’re added to its permanent archive, CSV files in this site’s repository (below). Nothing is kept anywhere else.
  3. The record reaches back before the Worker. CBP keeps no past readings, only the one posted last. The Worker began recording on October 14, 2026; the readings from September 13 to then come from an independent public archive that saved CBP’s whole feed about once an hour (gptcbp/border-crossing-data), read with the same code the Worker uses. Where both have a reading they agree almost every time; the archive missed some hours, so those weeks rest on fewer readings.
  4. Unknown is not zero. When lanes are closed or the update is pending, CBP posts no wait. Those are stored as blanks, not as zero minutes, and averages skip them. Counting them as zero would make a crossing that’s often closed look fast.
  5. The averages are the last 30 days. For each crossing, each day of the week and each hour, the page shows the average posted wait. With only a few weeks on record an hour may rest on two or three readings, so the pages say how many readings they’re based on{% if b %}; the record started {{ b.since_en }}{% endif %}.
  6. CBP’s own history fills the gap. CBP also publishes, for every port, the average wait at each hour of each weekday of a month, from the year before. Each crossing page shows that for the current month, labeled as CBP’s, so the heat map is useful from the first day, and the board’s own averages take over once a crossing has a few days of readings.
  7. The pages are rebuilt at least once a day. A GitHub Action copies the Worker’s data into the site, so every number is in the HTML. The “right now” columns also refresh from the Worker when the page opens, cached for five minutes.

How to read it: Standard is the regular commercial lanes; FAST is the lane for carriers and drivers enrolled in CBP’s Free and Secure Trade program. Lanes open is standard plus FAST, out of the most the port has. The wait is CBP’s, rounded the way CBP rounds it; “no wait” is CBP’s “no delay”.

Source: U.S. Customs and Border Protection, Border Wait Times; readings from September 13 to October 14, 2026 as saved by gptcbp/border-crossing-data. The numbers are public; any mistakes in presenting them are mine. The Worker’s code is in the worker folder of this site’s repository, and how much of Cloudflare’s free plan it uses is on the Worker usage page.
